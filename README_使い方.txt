【使い方】

【最初に1回だけやること】

このツールを使うには、わんコメ側でコメント保存をONにする必要があります。

わんコメを開いて、
設定 → その他 から、

・コメントログを残す
・ログをファイルとしても書き出し

この2つをONにしてください。

そのあと、コメントが1個以上流れると、コメント保存ファイルが作られます。

【毎回やること】

1. わんコメを起動する
2. 02_起動する_配信終了投票くん.exe を起動する
3. 「わんコメログを自動で探す」を押す
4. OBSに 03_OBSに入れる_overlay.html を入れる

【見つからない時】

わんコメ側のコメント保存設定がOFFかもしれません。
「最初に1回だけやること」を確認してください。

【リスナーが打つコマンド】

寝ろ派:
!寝ろ
!終了

続行派:
!続行
!まだ

【大事】

このバージョンでは配信は自動で切れません。
投票結果が画面に出るだけです。
